Student Management System

A simple Student Management System built using Python and CSV file handling.

📌 Features

- Add a new student
- View all students
- Update student information
- Delete a student
- Store student data in a CSV file
- Simple menu-driven interface

🛠️ Technologies Used

- Python
- CSV File Handling

📂 Project Structure

Student-Management-System/
│
├── main.py
├── students.csv
└── README.md

📊 Student Data

The "students.csv" file stores student information such as:

- Student ID
- Name
- Age
- Class
- Marks

▶️ How to Run

1. Download or clone this repository.
2. Open the project in Python/Pydroid 3.
3. Run "main.py".
4. Select an option from the menu.
